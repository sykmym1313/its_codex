# 과제 001: 배송비 계산 버그 수정

## 상황

온라인 쇼핑몰에서 일부 주문의 배송비가 정책과 다르게 계산됩니다.
`shipping.py`의 `calculate_shipping_fee` 함수를 조사하고 수정하세요.

## 요구사항

- 입력 `order_amount`는 상품 주문 금액이며, 단위는 원입니다.
- 입력은 항상 0 이상의 정수입니다. 음수, 소수, 문자열은 이번 과제 범위 밖입니다.
- 주문 금액이 **30,000원 이상**이면 배송비는 **0원**입니다.
- 주문 금액이 **30,000원 미만**이면 배송비는 **3,000원**입니다. 0원 주문도 포함됩니다.
- 함수는 배송비를 정수로 반환합니다.

## 수정 범위와 완료 조건

1. `shipping.py`의 함수 구현만 수정합니다.
2. 테스트, 요구사항, pytest 설정을 변경하지 않습니다.
3. `python -m pytest -q tests/test_shipping.py` 실행 시 7개 테스트가 모두 통과해야 합니다.
